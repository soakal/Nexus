## Open / unresolved items

- **Unrestricted `claude-unraid-deploy` SSH key still live on Unraid.** A full-root (unrestricted)
  key is silently re-persisted into `authorized_keys` on every Unraid boot via a `# BEGIN/END
  claude-unraid-deploy-key` block in `/boot/config/go`. Its origin/purpose was never investigated
  and no decision (keep/scope-down/retire) was made. — `NEXUS-Bug-Fixes.md` (2026-08-08 entry,
  "Still open"). Worth surfacing now: it's a standing full-root credential with no documented
  owner or rationale, and nothing since 2026-08-08 (including CLAUDE.md's own changelog) shows it
  was ever resolved.

- **Proxmox integration has no TLS/TOFU pinning (F14).** `backend/integrations/proxmox.py` still
  opens every request with `verify=False` (confirmed live in code, all 5 call sites). UniFi and
  Unraid both got TOFU host-key/cert pinning after a similar finding; Proxmox never did. —
  `NEXUS-Bug-Fixes.md` (2026-07-28 security-fix entry, F14 listed "Open"). Stale: flagged over a
  month ago, still true today.

- **Brain Organizer has no per-run file cap.** The `max_files_per_run` safety TODO ("cap how many
  files are processed in one run, e.g. 20") is documented in two notes but never implemented —
  confirmed by grep: no `max_files_per_run`/`MAX_FILES_PER_RUN` anywhere in
  `modules/brain-organizer/`. A large unexpected batch landing in `Brain/raw/` could still cause
  runaway API spend in one nightly run. — `NEXUS.md` and `Obsidian.md` ("TODO — Safety" sections).

- **HA garage-door alerting has no auto-close, escalation, or acknowledgment tracking.** Known
  gaps as of 2026-08-08: only a single 30-minute threshold alert, no re-alert/escalation cadence,
  no tracking of whether a human ever acted on an alert. A real incident that same day saw two
  separate garage-open alerts fire (16:03 and 21:09 UTC) with no automated closure in between. —
  `Home-Assistant.md`.

- **HA has a large, never-triaged cluster of anomalous/spoofed device-tracker MACs plus
  200-300+ flagged entities.** Trackers with clearly synthetic MACs (`00:00:ff:ff:ff:ff`,
  `00:01:00:00:00:00`, `aa:ff:00:00:aa:ff`) haven't been confirmed as HA integration artifacts vs.
  real rogue devices against the UniFi controller; the broader flagged-entity count creates noise
  that risks masking real issues over time. — `Home-Assistant.md`.
