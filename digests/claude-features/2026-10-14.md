# Claude + AI Digest — 2026-10-14

## 1. MCP deny/ask rules could silently skip servers with a double underscore in their name [New capability — priority watch-list]
Claude Code 2.1.299 (official GitHub `CHANGELOG.md`, high confidence) fixes two related MCP permission bugs: deny/ask rules written as `mcp__<server>` weren't applying when the server's *normalized* name itself contained a double underscore, and the matching behavior for `mcp__a`-style allow rules was tightened so `mcp__a` now only ever matches a server literally named `a` — a server whose real name contains `__` needs the rule written as `mcp__<server>__*`. This is exactly the kind of permission-rule bypass the priority watch-list flags.
Tie-in: worth a one-time check of any `mcp__`-prefixed allow/deny/ask rules in Claude Code settings for MCP_Obsidian or the Chrome browser-automation MCP server — if either server's configured/normalized name has an underscore in it, a rule that looked like it was gating that server may not have been enforced pre-2.1.299, and the matching got stricter in the same release.

## 2. Idle terminal sessions now auto-compact before the 1-hour prompt cache expires [New capability]
Also 2.1.299: a 200K+ token conversation left idle for ~54 minutes gets compacted automatically before the hourly cache window lapses, so the next message doesn't reprocess the whole history. Tunable via `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` or disabled with `"idleCompaction": false` (needs 2.1.290+).
Tie-in: relevant to Council Loop's unattended `/loop` sessions, which can sit idle for long stretches between Arbiter/Engineer/Realist turns on a big task — this should mean fewer expensive full-context reprocesses on resume, with no action needed on Brian's part.
