# Claude + AI Digest — 2026-11-10

**1. [New capability] Claude Code 2.1.321 closes several real permission/sandbox bypasses.** Shipped 2026-11-09 (dated via npm registry; the changelog itself carries no dates). Fixed: a read-only Bash command could run outside the sandbox with no prompt; Bash permission checks could judge a file write against the wrong folder; deny rules/protected-file prompts didn't apply to the actual file a `cp`/`mv` into a directory writes, including when invoked by full path (`/bin/cp`); and `grep -r foo "$PWD/src"` skipped a prompt the same path typed literally would trigger. Source: official GitHub CHANGELOG.md, paraphrased not quoted. (2.1.322, same day/next, adds only Vertex fast-mode — nothing else.) No new model pricing/deprecation date, and no MCP spec/SDK or Batch-API change surfaced this window (`mcp`/`starlette` unchanged on PyPI since the last check).
Tie-in: **Council Loop** auto-commits unattended on Engineer/Realist acceptance — exactly the class of bypass (path-invocation, wrong-folder checks, deny rules missing the real write target) that matters for a loop writing files with nobody watching. Worth checking its config's permission mode against this list.

**2. [New capability] Anthropic Python SDK 2.7.0 (2026-11-09).** Mostly Bedrock/Vertex/Foundry client fixes (missing `parse`/`count_tokens` on some wrapped responses, header/query-param handling, structured-output schemas keeping `const` correctly) plus model-ID support for `claude-fable-5-2` and the paired invite-only `claude-mythos-5-2` (Mythos = same weights as the matching Fable release, different safety/access layer). Source: SDK's own CHANGELOG.md.
Tie-in: **NEXUS** pins `anthropic==1.2.0` in `requirements.txt`, now 5+ major versions behind. Nothing in 2.7.0 looks load-bearing for NEXUS today, but the gap is worth a glance before the next dependency bump.

**3. [New technique] Simon Willison's `claude-code-transcripts` CLI.** Turns a Claude Code session — local, or pulled from Claude Code for web via a reverse-engineered API — into paginated, searchable, publishable HTML, including the hidden extended-thinking traces raw terminal output doesn't show. `uvx claude-code-transcripts`, no install needed; released Dec 2025, still actively extended (search added, a TS port and a Codex-session fork exist). Source: Willison's own blog post.
Tie-in: a natural fit for reviewing **Council Loop** run history or **Codex verify** sessions after the fact — a shareable HTML transcript with reasoning visible beats scrolling raw terminal output when judging whether an auto-accepted commit was actually sound.

**4.
