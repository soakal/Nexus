## 1. Claude Code v2.1.268: gateway-side pricing sync, a 2.1.265 regression fixed, WebFetch timeout [New capability]
Confirmed via the raw GitHub changelog (primary source) — genuinely new since the 09-10 digest's v2.1.267 coverage. Three changes: an org `gateway.yaml` can now set `pricing:` so signed-in Claude Code clients see the same rates in `/cost` and telemetry as the gateway actually charges; a regression since 2.1.265 that made every turn fail with HTTP 400 on third-party Anthropic-compatible endpoints (`ANTHROPIC_BASE_URL`) is fixed; and `WebFetch` no longer hangs forever against a server that holds the response open without finishing — it now times out at 300s. Tie-in: the WebFetch timeout fix is directly relevant to this digest's own pipeline (WebFetch is one of its three core tools) and to any custom tooling Brian has built around it; the gateway pricing sync only matters if NEXUS or another project routes Claude traffic through an org-managed gateway, which isn't the case today.

## 4. DeepSeek ships V4.1-Flash, claims it beats its own flagship and edges out Opus 5 on Terminal-Bench [Other AI]
High confidence — corroborated by DeepSeek's own announcement plus SiliconANGLE and TechNode coverage, all dated 2026-09-10 (within the lookback window). V4.1-Flash is a 552B-parameter MoE model (a new causal encoder/decoder design keeps only 8B params active on the prompt, 16B while generating) that DeepSeek says beats its larger V4-Pro on performance, cost, speed, and runtime — scoring 90.6 on Terminal-Bench 2.1 versus Opus 5's 89.1 and GPT-5.6 Sol's 88.8. It also compresses KV-cache to ~890 bytes/token (about a quarter of V4-Flash's footprint) via 4-bit float storage. Starting Sept 14, DeepSeek is routing all V4-Pro API traffic to this smaller model at its cheaper rate ($0.22/M input, $0.66/M output, 1M context) until a V4.1-Pro ships. Worth knowing as a builder-space development — a Terminal-Bench score ahead of Opus 5 from an open-weight model at a fraction of frontier pricing is a notable competitive data point, independent of any tie-in to Brian's own tools.
