## 1. Claude Code v2.1.274 [New capability]
Confirmed via the official CHANGELOG.md on GitHub (primary source) — one release since yesterday's v2.1.273. Most notable fix: an active `/goal` is no longer lost when a session resumes after compaction (previously it could silently drop). Also: corrupted transcripts now self-heal instead of getting stuck retrying "unexpected tool_use_id" 400 errors, hook-driven sessions that hit "Prompt is too long" now compact instead of erroring, and a new `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` env var controls how long the first turn waits on connecting MCP servers. Tie-in: Council Loop drives its Arbiter/Engineer/Realist cycle via `/loop /goal` — the compaction bug this patch fixes is exactly the failure mode that could silently derail a long autonomous Council Loop run if a session compacted mid-cycle.
