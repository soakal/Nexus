# Claude + AI Digest — 2026-08-29

## 1. Claude Code v2.1.251: model-switch hooks, prompt-cache visibility in `/cost`, and a sandbox-hardening bundle [New capability]
Confirmed via the official CHANGELOG.md on GitHub (primary source, high confidence) — new since last digest's v2.1.248 coverage (v2.1.250 in between was bug-fixes-only). Headline additions: `PreModelSwitch`/`PostModelSwitch` hook events that can block, confirm, or annotate a model switch; a per-session prompt-cache line on `/cost` (hit ratio, misses, tokens re-cached, warm/cold) plus a matching `prompt_cache` status-line field; live streaming of a foreground subagent's tool calls/results to Remote Control clients (background subagents still show status only); and `attach`/`logs`/`stop`/`respawn`/`rm` added to `claude --help` for background sessions. The same release also closed several real sandbox/permission gaps: a symlink swapped into the working directory after the permission check could redirect a Read/Write/Edit outside the approved location, a plugin marketplace entry could point a command outside the plugin directory, and settings that terminate sandbox TLS, route sandbox traffic through a proxy, inject credentials, or otherwise weaken sandbox isolation now require explicit approval before they apply. Tie-in: the new `/cost` prompt-cache line is a concrete way to check whether a long-running Council Loop or SOPForge session is actually landing cache hits rather than inferring it from spend alone; the sandbox-hardening fixes are relevant background if any of Brian's autonomous loops ever run inside a Claude Code sandbox rather than NEXUS's own broker.

## 4. Google DeepMind's "double-blind" AI evaluation pilot [Other AI]
DeepMind's own newsroom (deepmind.google/blog, primary source, high confidence) posted Aug 27, 2026 that it piloted the first double-blind AI evaluations, using cryptographically secure environments so a model's benchmark results can be verified by a third party without the lab seeing the test set or the evaluator seeing which model produced which answer. This targets the "we grade our own homework" credibility problem in every lab's self-reported benchmark numbers.
