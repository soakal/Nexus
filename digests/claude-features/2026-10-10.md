# Claude + AI Digest — 2026-10-10

## 1. Claude Code 2.1.296 ships — a real Bash permission-auto-approval bypass closed, plus hook/MCP/Windows fixes [New capability]
Confirmed from the official `CHANGELOG.md` on GitHub (high confidence). Fixed: Bash permission checks were auto-approving commands that assign the `BASH_ARGV0` shell variable and then use it — a real bypass (a command disguised via its own argv0 could dodge the permission check that would normally catch it) — these now prompt for approval like any other command. Also fixed in the same release: managed `PreToolUse`/prompt hooks that deny or block a call were letting the turn continue anyway instead of ending it; headless sessions starting a disabled `.mcp.json`/plugin MCP server after a directory change; and (Windows) `rm -rf /c/Users/<name>` in Git Bash not asking for confirmation under bypass-permissions mode. npm dist-tags: `stable` is now 2.1.287, `latest`/`next` 2.1.296 — the stable-vs-latest gap holds at 9 releases, same as yesterday.
Tie-in: Council Loop's autonomous `/loop` build cycle and the ponytail-mode skill both lean on Claude Code's own permission/hook gating to keep an unattended run safe — worth a one-time check of whether either config's allow-rules ever matched an argv0-style command pattern that this fix will now start prompting for instead of silently approving, since that could stall an unattended loop waiting on a prompt nobody's there to answer.

## 2. MCP server/tool description limits doubled, and Sonnet 5.5 cache reads get cheaper [New capability]
Same 2.1.296 `CHANGELOG.md` (high confidence). Changed: the default character limit on MCP tool descriptions sent up front and on MCP server instructions moved from 2,048 to 4,096 (distinct from Oct 9's 16,384-char change, which was specific to tool-search-loaded descriptions). Pricing: `/cost`, the status line, `--max-budget-usd`, and the SDK's cost figures now price Sonnet 5.5 cache reads at $0.10/MTok, down from $0.20.
Tie-in: NEXUS pins `mcp==1.9.4` in `requirements.txt` specifically because a prior `mcp` bump once pulled in a `starlette` release that broke FastAPI's `<0.39.0` pin — this description-limit change is client-side (Claude Code), not a protocol bump, so it shouldn't touch that pin, but it's worth knowing if MCP_Obsidian's server instructions or tool descriptions were ever getting truncated. The cache-price cut is Sonnet 5.5-specific; NEXUS's own `SONNET_MODEL` in `backend/agents/router.py` is still pinned to plain `claude-sonnet-5`, so it doesn't benefit directly.

## 3. Claude Sonnet 4.5 API deprecation is now official: retires November 30, 2026, replacement is Sonnet 5.5 [New capability]
Confirmed directly from Anthropic's own model-deprecations page (high confidence — an earlier secondary-source claim about this exact date is now verified against the primary source). `claude-sonnet-4-5-20250929` was deprecated September 30, 2026, and will stop serving requests after November 30, 2026; Anthropic's listed replacement is `claude-sonnet-5-5`, not plain `claude-sonnet-5`.
Tie-in: NEXUS's `_PRICE_PER_MTOK` table in `backend/agents/router.py` has no entry for `claude-sonnet-4-5-20250929` at all — its own migration history jumped straight from `claude-sonnet-4-6` to `claude-sonnet-5` — so this retirement doesn't hit NEXUS's live pin or price table. It does confirm Sonnet 5.5, not Sonnet 5, is Anthropic's current recommended ceiling if `SONNET_MODEL` is ever bumped again.
