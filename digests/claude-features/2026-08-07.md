## 3. Agent Skill malware can evade scanners via "SkillCloak" obfuscation [New technique]
Academic research (arXiv 2607.02357, "Cloak and Detonate") plus corroborating coverage (The Hacker News, GBHackers, cybersecuritynews.com — multiple independent outlets, moderate-high confidence) found that malicious Claude Code / Codex agent skills can be structurally obfuscated to evade over 90% of the 8 scanners tested, with no loss of the skill's actual malicious function — attackers have used this to steal browser credentials, SSH keys, and crypto wallet data through booby-trapped skills pulled from public marketplaces. Directly relevant to Brian's skill-heavy workflow (custom skills, marketplace installs): worth treating any third-party skill install with the same suspicion as an unreviewed dependency, and it's likely why Claude Code just added SHA-256 archive verification and marketplace owner-wildcarding (item 1) — a static scanner alone isn't the safety net it looks like.
