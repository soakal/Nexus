# Claude + AI Digest — 2026-09-29

## 1. Claude Sonnet 5.5 ships as the new default Sonnet model [New capability]
Anthropic released Claude Sonnet 5.5 on Sept 28 — 1M context window, 30%+ faster and up to 30% cheaper than Sonnet 5, positioned as the fast/cheap complement to Opus 5.5 for well-scoped everyday tasks, bug fixes, and document/slide/spreadsheet work. Claude Code 2.1.284 shipped the same day with Sonnet 5.5 as its new default (Medium effort by default) plus smaller fixes: a "yes, but ask again next time" option for file-read auto-approvals, dollar-amount display in usage tracking, and fixes for damaged response streams and persistent "prompt is too long" errors after compaction. Confirmed via the official GitHub changelog and Anthropic's own announcement page (high confidence).
Tie-in: worth checking whether `orchestrator_executor_model`/`orchestrator_planner_model` in NEXUS's `backend/config.py` should move off the current pinned Sonnet 5 string once 5.5 pricing/availability settles — the whole point of those being configurable was to ride model/cost improvements without a redesign.

## 2. "Plan mode is dead" — a widely-discussed reframe of when to plan vs. just build [New technique]
A Sept 24 post by Ayman Nadeem (founder of a coding app called Nuanced) argued that Claude Code's plan mode — read/explore/write-a-plan-then-approve — has outlived its main original purpose: models now understand intent well enough that exhaustive upfront specification is "an expensive ceremony" rather than a necessary control. It hit the HN front page (confirmed real thread, high engagement) and was covered by several dev blogs the same week. The piece doesn't claim plan mode was removed (Shift+Tab/`/plan`/`--permission-mode plan` all still work) — the claim is narrower: it shouldn't be Brian's automatic *first* step for well-understood tasks, with a lighter-weight human-legibility check substituted instead. Couldn't confirm the exact alternative workflow the author proposes (the source blog and HN itself were unreachable from this session — network egress blocked both domains), so treat the "what to do instead" half as unconfirmed pending a direct read.
Tie-in: directly relevant to how Brian currently drives orchestrator/subagent work across NEXUS, Council Loop, and SOPForge — if he's defaulting into plan mode for changes that are actually well-scoped, this is a data point (not a directive) that skipping straight to implementation-with-review may now be competitive for those cases.

## 4. OpenAI reportedly scraps GPT-6.1 "Astra" release over safety concerns [Other AI]
The Wall Street Journal (via Bloomberg/CNBC, Sept 28) reported OpenAI abandoned plans to ship an upcoming model, GPT-6.1 Astra, after it didn't meet internal safety standards — OpenAI is reportedly tightening safeguards following a string of AI-enabled hacking incidents. Notable timing: the report landed one day before OpenAI's annual developer conference. Separately, both xAI (Grok Voice Transcribe 2.0) and Google (Gemini 3.8 Live) shipped voice-focused updates this week, but neither rises to the same significance as a major flagship model being pulled for safety reasons.
