## 1. Claude Code 2.1.312 ships — and quietly stops sending the `safety_event` telemetry it added five releases ago [New capability]
Confirmed directly against the official CHANGELOG.md (high confidence): `latest`/`next` moved 2.1.311 → 2.1.312. The changelog's own line is terse: "Stopped sending the `claude_code.safety_event` OpenTelemetry event." That's the same event 2.1.307 added on 2026-10-21 (covered in the 2026-10-22 digest) — it fired whenever a permission rule, auto mode, a safety check, a hook, or the sandbox stopped, prompted, or sent back a tool call, and was flagged then as a plausible model for an `ActionLog`-style audit stream. No reason is given for turning it off again after one week, and no replacement signal is mentioned. Smaller items in the same release: a command with an invalid name no longer blocks all other commands from loading, cloud routines can now set an effort level, and prompt/agent hooks are capped at 24 concurrent runs per session.
Tie-in: no action needed in **NEXUS** — this was never wired into anything there, just noted as an interesting pattern. Worth knowing only so a stale assumption ("Claude Code now emits a safety-event stream") doesn't linger from the earlier digest.
