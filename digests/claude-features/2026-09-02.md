# Claude + AI Digest — 2026-09-02

## 1. Claude Fable 5.1 and Mythos 5.1 launched, cache-read pricing cut 75% [New capability]
Anthropic shipped Claude Fable 5.1 and the restricted-access Claude Mythos 5.1 on Sept 1 (primary source: Anthropic's own announcement page + system card PDF, corroborated by TechSpot/VentureBeat/MarkTechPost coverage). Fable 5.1 keeps Fable 5's $10/$50-per-Mtok rates and 1M-token context, but cached-input reads drop from $1 to $0.25 per Mtok (a 75% cut) — Anthropic estimates ~25% cheaper typical workloads and up to ~45% cheaper highly agentic ones. Mythos 5.1 is the same underlying model with cyber/biosecurity safeguards relaxed for vetted orgs in a restricted program, not something Brian can access directly. Tie-in: this is a free cost cut on anything already leaning on prompt caching — Council Loop's long autonomous sessions and NEXUS's own router.py caching would both benefit automatically once billing reflects the new model.

## 2. Claude Code 2.1.252–2.1.258: subagent model forcing, plus a fix for exactly this kind of scheduled session [New capability]
The CLI changelog moved from v2.1.251 (last covered) to v2.1.258 as of Sept 1 (source: official CHANGELOG.md, high confidence). Two items stand out: a new `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1` env var that pins every subagent/teammate/workflow agent — including the built-in Explore and Plan agents — onto one chosen model (`CLAUDE_CODE_SUBAGENT_MODEL`), useful for cost control or for A/B-testing one model across a whole agent roster with a single flag; and a v2.1.258 fix for "remote/scheduled sessions failing with permission approval message errors" — the exact class of session this digest routine itself runs as. Also smaller: per-session time-format/timezone settings and a `/doctor` warning for stale sandbox mask files.
