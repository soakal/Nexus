## 1. Claude Code v2.1.248: cross-session messaging (`SendMessage`/`ListAgents`) between sessions on the same machine [New capability]
Confirmed via the official GitHub CHANGELOG (primary source, high confidence) — new since last digest's cutoff at v2.1.247. Tie-in: same-machine cross-session messaging is a real coordination primitive for how Brian runs parallel long-running sessions (Council Loop, SOPForge, this digest routine) — it's local-machine only today, not cross-host, so it wouldn't bridge a devbox session and a nexus-lxc session, but worth knowing about if two Claude Code sessions on the same box ever need to hand off context directly instead of going through a shared file.
