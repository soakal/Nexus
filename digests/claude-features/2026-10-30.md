## 1. Claude Code 2.1.314 adds a hard filesystem guardrail: Write/Edit/NotebookEdit blocked outside the working directory in EVERY permission mode [New capability]
Confirmed directly against the official CHANGELOG.md (high confidence; npm registry shows 2.1.314 published 2026-10-30T00:12 UTC, so this is new since yesterday's digest, which only covered up through 2.1.312). The release adds a permission setting that stops Write, Edit, and NotebookEdit from touching paths outside the working directories — and per the changelog's own wording this applies "in every permission mode," which reads as covering auto mode and `--dangerously-skip-permissions`/bypass modes too, not just the default ask-first mode.
