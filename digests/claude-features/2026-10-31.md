# Claude + AI Digest — 2026-10-31

## 1. Claude Code 2.1.316: Opus 4.8 fast mode deprecated, MCP gateways now enforce blocked-model lists, new subagent-effort env vars [New capability]
Confirmed directly against the official CHANGELOG.md (high confidence; this release landed after yesterday's digest, which covered only up through 2.1.314). Priority-watchlist hit: fast mode for Opus 4.8 is deprecated as of October 30, 2026 and will be removed November 30, 2026 (requests after that return an error instead of silently falling back to standard Opus 4.8); Anthropic's stated migration target is Opus 5.5. Also in this release: Claude Apps gateways now check every model a request names against `availableModels`/`deniedModels`/`models` and return a 400 if it's blocked (previously only some checks applied); a new `layered` gateway policy mode; and two new env vars, `CLAUDE_CODE_SUBAGENT_EFFORT` (sets subagents' effort level) and `CLAUDE_CODE_DISABLE_ULTRATHINK` (turns off the `ultrathink` keyword).
Tie-in: the fast-mode deprecation doesn't touch NEXUS's live spend — `backend/agents/router.py` already migrated its `OPUS_MODEL` constant off `claude-opus-4-8` onto `claude-opus-5-5` on 2026-09-28, and `_PRICE_PER_MTOK` only keeps the old `claude-opus-4-8` entry for historical `SpendLog` rows, not active calls. `CLAUDE_CODE_SUBAGENT_EFFORT` is more interesting for **Council Loop** — its Arbiter/Opus-plans, Engineer/Sonnet-implements, Realist/Sonnet-reviews roles could each get a tuned effort level via this env var instead of per-call config, if the driver sets it per role.
