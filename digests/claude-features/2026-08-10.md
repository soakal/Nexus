## 2. Auto mode's full configuration surface: hard_deny/soft_deny/allow rules, trusted-infrastructure context, and a critique command [New technique]
With auto mode becoming the Claude Code default on August 14 for Pro/Max/Team (per the announcement flagged yesterday), the actual config reference (code.claude.com/docs/en/auto-mode-config, fetched directly — high confidence) turns out to have real depth Brian will likely want before that date. The classifier's decisions are steered by an `autoMode` settings block (in `~/.claude/settings.json` or managed settings — NOT read from `.claude/settings.local.json`, closing a repo-injection risk) with four levers: `environment` (prose description of your trusted repos/domains/buckets — the classifier treats anything unlisted as a possible exfiltration target), `hard_deny` (unconditional, no override), `soft_deny` (blocks unless user intent or an `allow` rule clears it), and `allow` (exceptions). All four accept the literal string `"$defaults"` to extend rather than replace Anthropic's built-in rule lists. `autoMode.classifyAllShell: true` routes every Bash/PowerShell command through the classifier instead of letting narrow allow-rules bypass it. Three new CLI subcommands: `claude auto-mode defaults` (print built-in rules), `claude auto-mode config` (print your effective merged rules), and `claude auto-mode critique` (AI review of your custom rules for ambiguity/false-positive risk). Tie-in: this is close kin to NEXUS's own broker (`backend/safety/broker.py`) — risk classification, allow/needs_confirm/forbid tiers, an override/policy-promotion layer — except Anthropic is shipping it as Claude Code's own default runtime. Worth setting up an `autoMode.environment` block before the Aug 14 switchover (homelab domains, the NEXUS/Council-loop/SOPForge repos) so routine work doesn't start hitting classifier prompts it wasn't hitting before, and `claude auto-mode critique` is a free sanity check if Brian ever writes custom `soft_deny`/`hard_deny` rules of his own (e.g. for Council-loop's autonomous commit loop).
