## 1. Claude Code v2.1.273 [New capability]
Confirmed via the official CHANGELOG.md on GitHub (primary source) — one new release since yesterday's digest (which topped out at v2.1.272/2.1.273 boundary). Highlights: new opt-in LLM-gateway headers (`x-claude-code-request-class`, `x-claude-code-agent-type`) for routing/observability on custom gateways; MCP servers now surface a notification with reconnection guidance when they disconnect mid-session instead of failing silently; sessions started via remote-control can now be forked into background sessions; and a real security-relevant fix — `permissions.blockReadsOutsideWorkingDirectories` was failing to block dangerous `rm` commands hidden inside subshells. Also fixed: managed settings being silently ignored when server-managed settings were also present, skills synced from claude.ai persisting after an org disables them, and premature auto-compaction caused by a miscounted context meter. Tie-in: the subshell-hidden-`rm` fix is directly relevant to how heavily NEXUS's own CLAUDE.md leans on `permissions.blockReadsOutsideWorkingDirectories`-style guardrails for autonomous agent work — worth confirming this patch is picked up wherever that permission is configured.
