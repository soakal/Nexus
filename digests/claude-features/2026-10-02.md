## 1. Claude Code 2.1.287: "Mods" — plugins that run inside the CLI itself, plus a built-in "You Should Know" watcher [New capability]
A new plugin tier shipped yesterday: a mod is JS/TS code that runs *inside* the Claude Code process (not an external script like a settings hook, skill, or MCP server), so it can draw its own panes/bands in the UI, redraw parts of Claude Code's own interface, intercept or rewrite a tool call before it runs, or add an instant `/command`. Official docs give a full worked example (a mod that counts tool calls and shows the count next to the spinner) and list the built-in mods already shipping, including `cc-plugin-you-should-know` — an opt-in side-agent that watches a long session and surfaces a note above the prompt when it catches something you or Claude might miss (disabled by default, `/plugin enable cc-plugin-you-should-know@builtin`). You can also just describe what you want in a session and have Claude write the mod for you. Confirmed via Claude Code's own docs site (code.claude.com/docs/en/plugins/mods/overview) and the official GitHub changelog/release notes, high confidence.
Tie-in: this is a direct hit on the `plugin-authoring` skill already in this account's skill list — that skill is literally the one the built-in `cc-plugin-plugin-authoring` mod gives Claude for writing mods, so the skill isn't a separate workaround, it's first-party support for exactly this feature. Worth a look specifically for the "You Should Know" built-in: a free second-pair-of-eyes watcher on long Council Loop or NEXUS sessions, for free, before building a custom equivalent.
