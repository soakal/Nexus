## 1. Claude Code v2.1.243: keyless sign-in via Anthropic Console, plus org-scoped model/cache controls [New capability]
Confirmed via the official GitHub changelog (primary source, high confidence), released after last digest's cutoff (2026-08-23 covered up through v2.1.239). v2.1.243 adds keyless sign-in through the Anthropic Console (no API key needed to authenticate a session), a `modelPicker` setting for curating which models show up in the picker, `promptCacheTtl` for organizations, and `modelPricing` for contracted rates. The last three are org/enterprise-scoped and don't apply to an individual account; keyless sign-in is the one piece that could matter for any account — one less credential to manage when starting a fresh session on a new machine.

## 2. Claude Code v2.1.245–246: Bash-wildcard safety warning, an Auto mode tab in permissions, turn-duration timing [New capability]
Confirmed via the same GitHub changelog, high confidence. v2.1.246 adds a startup warning when a Bash permission rule uses a wildcard *before* the subcommand (e.g. catching an overly-broad allow rule before it silently grants more than intended), a dedicated Auto mode tab in the permissions UI, and completion times now shown alongside turn duration. v2.1.245 separately fixed a crash on Linux distros shipping glibc 2.44 (Arch, CachyOS, Fedora Rawhide — not relevant to Debian/Ubuntu boxes like devbox or nexus-lxc, but worth knowing if any machine in the fleet ever moves to a rolling-release distro). Tie-in: the wildcard-warning is worth a glance against this project's own `.claude/settings.json` Bash allowlist next time it's touched — a rule like `npm run *` written the tighter way in mind can still be broader than intended, and this now flags that at startup instead of silently.
