# Claude + AI Digest — 2026-09-30

## 1. Claude Code 2.1.285 ships `claude --desktop`, a WebFetch kill-switch, and provider allowlisting [New capability]
The CLI's latest release adds `claude --desktop` (opens the Claude desktop app on the current directory, or on a specific session via `--continue`/`--resume <id>`), a `CLAUDE_CODE_DISABLE_WEB_FETCH` env var to turn off the WebFetch tool entirely, a `claude plugin configure <plugin>` command to inspect/set a plugin's options from stdin, and an `allowedProviders` managed setting to lock a machine to specific API providers (Anthropic API, Bedrock, Vertex, a custom gateway, etc.). Also fixed: forked subagents now correctly inherit their parent's permission mode instead of being able to exit plan mode on their own, and cloud sessions no longer refuse artifact updates after a restart mid-compaction. Confirmed via the official GitHub changelog (raw file, high confidence).
Tie-in: the `allowedProviders` setting is closer to a fleet-management control than something relevant to Brian's own single-machine setup; `claude --desktop` is a minor convenience worth knowing about if he ever wants to hand a CLI session off to the desktop app mid-task.
