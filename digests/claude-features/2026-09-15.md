# Claude + AI Digest — 2026-09-15

## 1. Claude Code v2.1.271 and v2.1.272 [New capability]
Confirmed via the official CHANGELOG.md on GitHub (primary source) — genuinely new since yesterday's digest, which was still topped by v2.1.270. v2.1.271 is the substantial one: fast mode now works in Claude Code Remote sessions (previously local-only per this repo's own CLAUDE.md note on `/fast`), mouse support landed in the `/config` panel, and — the notable one for a sandboxed-Bash-heavy setup — **per-command domain allowlists for sandboxed Bash/PowerShell commands**, letting a specific command reach specific domains instead of an all-or-nothing sandbox network policy. Also new: `omitClaudeMd` in agent frontmatter (lets a subagent skip loading the project's CLAUDE.md), managed-setting pricing multipliers up to 10x, and `--accept-command` for plugin installs. Fixes: cached org policies wrongly reused after account switches, cloud sessions rejecting subagent tool calls mid-approval, and Bash permission checks missing files after wildcards/variable expansion. v2.1.272 followed as an undetailed "bug fixes and reliability improvements" patch. Tie-in: `omitClaudeMd` is worth knowing about given NEXUS's CLAUDE.md is enormous — a subagent spawned for a narrow, self-contained task (e.g. one file's diff) could skip loading all of it if the context isn't needed, trimming tokens without touching the file itself. The per-command domain allowlist is also relevant to any sandboxed workflow that currently has to choose between "no network" and "any network" for a Bash step.
