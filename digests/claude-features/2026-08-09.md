## 1. Auto mode becomes the default permission mode in Claude Code, starting August 14 [New capability]
Per Anthropic's own blog post (claude.com/blog/auto-mode-default-in-claude-code, corroborated by 9to5Mac, the-decoder, and Anthropic's own Threads/X accounts — high confidence), new Claude Code sessions on Pro, Max, and Team plans will default to auto mode instead of per-command approval starting August 14: every action routes through a separate classifier trained to block irreversible/destructive/out-of-environment actions, rather than asking you to approve each command. Classifier token overhead doesn't count against Pro/Max/Team usage limits as of this change; if you've already set a default permission mode it won't be silently overridden.
