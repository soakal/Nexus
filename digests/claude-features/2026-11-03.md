# Claude + AI Digest — 2026-11-03

## 1. Claude Code 2.1.317 — Agent SDK hooks can now fail closed [New capability]
Found in the official changelog (high confidence, read directly off the raw CHANGELOG.md): Claude Code 2.1.317 (new since 2.1.316, the last version covered) adds `onFailure: "block"` for Agent SDK hook callbacks — previously a hook callback that errored let the action through silently (fail-open); this new option makes it block instead. Same release also adds a confirmation prompt before a web or shell tool call sends your account email address to the network, and a `/schedule` warning when a new cloud scheduled task picks up connectors you didn't ask for.
Tie-in: this is the Agent SDK's own hook API (for programmatically-built agents), not the Claude Code `settings.json` hooks Brian already uses for ponytail mode/Council Loop, so nothing changes for his existing setup — worth knowing only if he ever scripts something directly against the Agent SDK.

## 2. Anthropic Python SDK 2.4.0 (2026-11-02) — new session error types [New capability]
Found in the SDK's own CHANGELOG.md (high confidence). Released the day before this digest window closed: adds `tool_use_limit_reached_error` and `compaction_limit_reached_error` as distinct session error types, plus a batch of admin-only GA endpoints (analytics, spend limits, RBAC) aimed at orgs, not solo users.
Tie-in: **NEXUS**'s `requirements.txt` pins `anthropic==1.2.0` — three major versions behind current (2.4.0). That gap predates this release and isn't urgent, but a future bump would pick up the new structured error types, which could let `backend/agents/router.py`'s error handling distinguish a context-compaction failure from a tool-use-limit failure instead of falling into its generic exception path.
